Real-time Stock Price Data Analyzer

This is a real-time stock price data analyzer project which used popular open source technologies, such as Apache Kafka, Cassandra, Spark Streaming, Node.js, Redis, and D3.js.


Overview


What I have done in this project

I used Kafka to ingest the price data of different stocks from Google Financeand processed the raw data and calculated the average price of each stock using Spark Streaming. I persisted the raw data in Cassandra at the same time and optimized data storage schema to speed up data query performance. I also developed a dashboard web app using Redis, Node.js, D3.js and visualized the trend of the price of the stocks.
