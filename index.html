About me

Hello! I'm Yihang Fan, a Doctoral Researcher at the University of California, Irvine. Driven by a passion for discovery, my research focuses on:

  • Cardiovascular disease risk assessment and prevention, with a focus on lipoprotein(a), lipid disorders, and coronary artery calcium (CAC).
  • Cardiometabolic health and disparities, including type 2 diabetes, obesity, CKM syndrome, and GLP-1-based therapies.
  • Causal inference and longitudinal analysis of prospective cohorts and electronic health records to advance cardiovascular prevention.

When I'm not working, you can find me exploring new cultures through travel, experimenting with flavors in the kitchen, or practicing the violin, a lifelong passion I have been honing since the age of four.

I am driven by the belief that true medicine looks beyond the data to understand the person. I dedicate my career to academic discovery not just to treat disease, but to proactively foster global longevity and help diverse communities thrive.

RESEARCH

Graduate Research Assistant - University of California, Irvine

Advisor: Dr. Nathan Wong. April 2023 - present.

I design and conduct cardiovascular epidemiologic studies using large prospective cohorts and electronic health records to examine lipid disorders, cardiometabolic risk, and disparities in preventive care.

My experience includes developing analytic cohorts and data workflows using SQL, SAS, R, and Python. In this work, I regularly draw on the UC Health Data Warehouse, TriNetX, UK Biobank, and NIH-supported cardiovascular cohorts, while exploring patient cohorts using Epic Cosmos.

I apply advanced statistical techniques-such as multivariable regression, survival analysis, propensity score methods, and incidence rate estimation-to rigorously evaluate cardiovascular risk factors, treatment patterns, and clinical outcomes.

Additionally, I evaluate the impact of electronic health record messaging and best practice advisories on lipid testing, treatment, and overall cardiovascular risk management.

Throughout my research, I collaborate closely with clinical investigators and data scientists on study design, analysis, and interpretation, while regularly preparing first-author and coauthored manuscripts and conference presentations.

A Compiler based on Java Virtual Machine

Course Project. Jan. 2017 – Apr. 2017

In this project, I wrote a self-made compiler which can convert the source code to Java bytecode and run it on Java Virtual Machine. You can see the basic grammar of this language by click the button below. I built a scanner to implement the lexical analysis of the input character stream, and accomplished a recursive descent parser to implement the syntax analysis and generated an abstract syntax tree. I implemented the semantic analysis and type checking using LeBlanc-Cook symbol table and visitor pattern. Finally, I used the ASM Java bytecode manipulation framework to generate the Java bytecode of the source code and ran it on Java Virtual Machine.
